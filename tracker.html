⚠︎ Important on iPhone: Shortcuts open links in Safari, which keeps separate storage from a home-screen app. For auto-sync, use NutriTrack in Safari (bookmark it) rather than the installed icon — otherwise the synced data lands in the wrong place.
Set up (~3 min):
1. Open Shortcuts → new shortcut.
2. Find Health Samples → Steps → today → Calculate Statistics → Sum. Set variable Steps.
3. Repeat for Active Energy (Sum → var Burn), Body Mass (Latest Sample → var Weight), and Body Fat Percentage (Latest Sample → var Fat). Skip any your devices don't provide.
4. Text action: paste your sync URL and append ?steps=[Steps]&burn=[Burn]&weight=[Weight]&bodyfat=[Fat].
5. Open URLs with that text.
6. Automation → new Personal Automation → Time of Day (e.g. 10 PM) → run this shortcut daily; turn off “Ask Before Running”.
Done — each night your steps, calories and body stats log themselves.
If Starfit isn't already sharing with Apple Health, open the Starfit app → its settings → enable Apple Health / HealthKit and allow Weight & Body Fat.
