# Animal Sounds & Counting

A spoken preschool game: animal letter sounds, tap-to-count up to 25, and picture adding.
Works offline once it has been opened one time.

## Install on a phone or iPad
1. Open the game link (this folder on the site) in Safari (iPhone/iPad) or Chrome (Android).
2. Tap Share, then **Add to Home Screen**.
3. Open it once from the home screen while online. After that it plays with no internet.

## Updating
Change the files, then bump `VERSION` in `sw.js` so devices download the new copy.
